# Project Positioning

## Public Positioning

AI Portrait Prompt Lab is an open-source prompt workflow toolkit for creators who generate portrait images and image-to-video first frames.

The public repo should be described around:

- fashion portrait prompts
- travel portrait prompts
- guofeng fantasy character references
- image-to-video prompt stability
- reusable prompt modules
- positive and negative prompt pairing

## Avoid In Public Copy

Avoid positioning the project as an adult, NSFW, or sexually explicit prompt library. Do not use explicit preview images or language that suggests sexual acts, nudity, non-consensual content, minors, or pornography.

## Why This Angle

Prompt text alone is easy to copy. The useful part is the workflow:

- repeatable modules
- batch variants
- scene and outfit coordination
- image-to-video stability notes
- negative prompt hygiene
- Chinese creator-friendly presets
