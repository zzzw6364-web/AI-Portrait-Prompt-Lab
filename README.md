# AI Portrait Prompt Lab

Modular prompt generators for portrait, fashion, travel, guofeng fantasy, and image-to-video workflows.

This project is a set of standalone HTML prompt labs. Each lab helps creators assemble structured prompts from reusable modules: subject, outfit, scene, pose, camera, lighting, realism controls, positive prompt, and negative prompt.

## Labs

- `Guofeng Fantasy Prompt Lab`  
  Chinese fantasy costume prompts with outfit structure, fabric layers, jewelry, lighting, and stable composition.

- `Fashion Portrait Prompt Lab`  
  Modern fashion portrait prompts for editorial, street-style, evening gown, and commercial photography workflows.

- `Travel Portrait Prompt Lab`  
  Chinese and international travel portrait prompts with scene-to-outfit matching, coordinated shoes, props, and image-to-video stability notes.

## Features

- Standalone HTML files. No server required.
- Positive and negative prompts are generated together.
- Scene, outfit, pose, lens, lighting, and style modules are independently adjustable.
- Travel scenes can auto-match clothing style to the environment.
- Batch variants keep the main character anchor stable while changing replaceable modules.
- Image-to-video friendly wording for stable clothing edges, readable limbs, and clear faces.

## Use

Open `index.html` in a browser, then choose a lab.

You can also open any file in `apps/` directly.

## Safety And Scope

The public version is designed for fashion, portrait, travel, and stylized character reference workflows. It avoids explicit content and includes negative prompts against minors, nudity, sexual acts, wardrobe malfunction, broken anatomy, extra limbs, watermarks, and low-quality artifacts.
